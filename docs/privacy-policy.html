Privacy Policy

Last updated: August 2, 2026

This policy covers the Job Search Lens Chrome extension. It explains what the extension processes to provide its features, what stays in browser storage, and what the developer does not receive.

Developer receives Nothing automatically
Page content Processed transiently in the tab
Saved preferences Stored locally in Chrome

What the extension processes

Job Search Lens processes the minimum information needed for its user-facing features:

  • Visible website text to find saved keyword matches.
  • LinkedIn job-card labels such as Viewed, Saved, and Applied to determine which cards to dim.
  • Company size and LinkedIn employee-count text already present in the LinkedIn page so it can be shown closer to the job title.
  • The current tab URL when you open the popup, only to identify whether the active page supports LinkedIn tools and match navigation.

Page content and the current tab URL are processed in the browser. They are not retained as a browsing history and are not transmitted to the developer or a third party.

What is stored on your device

  • Keywords you save and whether each keyword is enabled.
  • The highlight color assigned to each keyword.
  • Pause state, dim-state toggles, and the optional all-site-highlighting preference.
  • The popup theme preference.

Keywords, colors, and feature settings are stored in chrome.storage.local. The popup theme is stored in the extension's own localStorage so it can be applied before the popup paints. Job Search Lens does not use Chrome Sync, and these values are not sent to a developer-controlled server.

Optional access outside LinkedIn

LinkedIn access is included because the extension's primary features run there automatically. Access to other HTTP and HTTPS websites is optional. Chrome asks for that broader access only after you turn on Highlight on all websites in the popup. You can turn the setting off to remove the optional access.

Diagnostics you choose to copy

When you click Diagnostics, Job Search Lens creates a support report locally and copies it to your clipboard. The report contains the extension version, connection and page-category status, detected-feature flags, and numeric counts. It excludes the page URL, page text, job and company names, and saved keyword values. The developer receives it only if you choose to share it.

What the developer does not collect

  • No names, email addresses, account credentials, or LinkedIn login information.
  • No job applications, browsing history, saved-job history, or page content.
  • No analytics events, telemetry, crash reports, advertising identifiers, or tracking pixels.
  • No payment or financial information.

The extension has no developer account system, backend service, advertising SDK, analytics SDK, or remote-code loader.

How information is used and shared

Information processed through Chrome APIs is used only to provide keyword highlighting, card dimming, company context, match navigation, context-menu capture, diagnostics, and user-controlled settings. Except for a privacy-safe diagnostic report you deliberately copy and share for support, no stored or processed information is transferred or made available for human review. Nothing is sold, rented, disclosed for advertising, or used for creditworthiness, lending, or unrelated profiling. A diagnostic report you share may be reviewed only to investigate the issue you reported.

Permissions

  • contextMenus — add text you select as a keyword through the right-click menu.
  • storage — save keywords and feature settings locally.
  • activeTab — let the popup check and communicate with the tab you are actively viewing after you open the popup.
  • scripting — register the highlighting helper when optional all-site highlighting is enabled.
  • https://www.linkedin.com/* — run LinkedIn Jobs highlighting, card dimming, and company-context features automatically.
  • http://*/* and https://*/* — optional host access requested only for all-site keyword highlighting.

Retention and deletion

Website content and active-tab information are processed transiently and are not retained. Saved keywords and preferences remain in extension-local storage until you change or remove them. Removing the extension through Chrome deletes its local extension storage. You can also remove individual keywords or turn off optional all-site access from the popup at any time.

Security and remote code

The extension uses a restrictive Manifest V3 content security policy and ships the JavaScript, CSS, and images it needs inside the extension package. It does not download or execute remote code and makes no requests to a developer-controlled endpoint. Your browser profile and device security still determine who can access locally stored extension settings.

Chrome Web Store Limited Use

Job Search Lens's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. That information is used only to provide or improve the extension's prominent user-facing features described above.

Product website

The product website contains no developer-added analytics, advertising, cookies, or tracking pixels. It is hosted on GitHub Pages, so GitHub may process ordinary web-request information under its own terms and privacy policy. Following an external link takes you to that site's privacy practices.

Policy changes

If the extension's data practices materially change, this policy and its “Last updated” date will be revised before the changed version is published.

Contact

For support or privacy questions, visit the support page or open an issue on the public issue tracker. Do not include private job-search or account information in a public issue.
